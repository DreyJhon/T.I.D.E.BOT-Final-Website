# T.I.D.E.BOT 🌊

**Trash Inspection and Debris Extraction Bot**

T.I.D.E.BOT is an Arduino-based semi-autonomous surface vehicle designed to collect floating solid waste along the shoreline of Pachoca, Calapan City, Oriental Mindoro, Philippines.

## Features
- ♻️ Floating waste collection
- 🤖 Arduino-based control system
- 🧭 Ultrasonic sensor-based obstacle detection
- 🚤 Surface navigation and propulsion
- 🔬 Interactive robotics simulation and research presentation

## Technologies Used
- Arduino Uno R3
- Ultrasonic sensors
- Brushless motors and Electronic Speed Controllers (ESCs)
- Lithium-polymer (LiPo) batteries
- HTML, CSS, and JavaScript for the interactive website

## Research Project

**Research Title:** *Design, Development, and Performance Evaluation of T.I.D.E.BOT: An Arduino-Based Semi-Autonomous Surface Vehicle for Shoreline Waste Collection in Pachoca, Calapan City*
